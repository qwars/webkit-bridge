# EWD — Emacs-клиент для WebKit Daemon

Emacs-клиент для демона [webkit-bridge](https://github.com/your-repo/webkit-bridge), обеспечивающий бесшовную автоматизацию браузера и веб-сёрфинг прямо из Emacs через WebKitGTK.

## 🎯 Обзор

**EWD (Emacs WebKit Daemon)** — это Emacs Lisp пакет, который подключается к демону `webkit-bridge` через Unix-сокет, используя протокол JSON-RPC 2.0. Он позволяет:

- Просматривать веб-страницы с помощью WebKitGTK, не покидая Emacs
- Автоматизировать веб-взаимодействия через выполнение JavaScript
- Управлять несколькими вкладками браузера через специальный буфер
- Программно извлекать веб-контент
- Интегрировать веб-сёрфинг в ваш рабочий процесс Emacs

EWD — это **не** браузер сам по себе. Это клиент, который взаимодействует с автономным демоном `webkit-bridge`, управляющим реальными экземплярами WebKitGTK.

## ✨ Возможности

### Управление вкладками
- Создание, закрытие, навигация и перезагрузка вкладок
- Специальный буфер `*ewd-tabs*` для визуального управления вкладками
- Автоматическое обновление списка при событиях (изменение заголовка, создание/закрытие вкладок)
- Визуальное различие между вкладками, принадлежащими Emacs (`*`), и внешними вкладками

### Выполнение JavaScript
- Выполнение произвольного JavaScript в контексте любой вкладки
- Получение результатов обратно в Emacs для дальнейшей обработки
- Идеально для веб-скрапинга и автоматизации

### Безопасность и изоляция
- **Контроль доступа на основе владельца**: Emacs может управлять только созданными им вкладками
- Вкладки, созданные другими клиентами (например, `wkctl` или другими экземплярами Emacs), видны, но не модифицируемы
- Автоматическая очистка: все вкладки, принадлежащие Emacs, закрываются при выходе из Emacs

### Реактивный UI
- Обновление в реальном времени при изменении заголовков вкладок
- Автоматическое обновление буфера при событиях создания/закрытия вкладок
- Защита буфера от редактирования с безопасным программным обновлением

### Бесшовная интеграция
- Автоподключение при первой команде (настраивается)
- Тихая очистка при выходе из Emacs (без запросов подтверждения)
- Поддержка UTF-8 для международного контента

## 📋 Требования

### Emacs
- **Emacs 30.1+** (протестировано)
- Должен работать с Emacs 27.1+ (не тестировалось)
- Скомпилирован с поддержкой `json-parse-string` (стандартно в современных сборках)

### Демон
- **Демон webkit-bridge** должен быть запущен
- Сокет доступен по адресу `$XDG_RUNTIME_DIR/webkit-bridge.sock` (по умолчанию)
- См. [README webkit-bridge](../README.md) для установки демона

### Система
- Unix-подобная ОС с поддержкой Unix domain sockets
- Linux, BSD, macOS (с соответствующими путями к сокетам)

## 🚀 Установка

### Ручная установка

1. Клонируйте или скопируйте `ewd.el` в ваш Emacs load path:
   ```bash
   mkdir -p ~/.emacs.d/lisp
   cp ewd.el ~/.emacs.d/lisp/
   ```

2. Добавьте в ваш `init.el`:
   ```elisp
   (add-to-list 'load-path "~/.emacs.d/lisp")
   (require 'ewd)
   ```

### Использование use-package

```elisp
(use-package ewd
  :load-path "~/.emacs.d/lisp/ewd"
  :bind-keymap ("C-c w" . ewd-command-map)
  :config
  (setq ewd-auto-connect t))
```

## ⚙️ Конфигурация

### Переменные настройки

Доступ через `M-x customize-group RET ewd RET`:

| Переменная | По умолчанию | Описание |
|------------|--------------|----------|
| `ewd-socket-path` | `nil` (автоопределение) | Путь к сокету демона. Если `nil`, используется `$XDG_RUNTIME_DIR/webkit-bridge.sock` или `/tmp/webkit-bridge.sock` |
| `ewd-default-visible` | `nil` | Видимость новых вкладок по умолчанию. Если `t`, вкладки открываются в GTK-окнах |
| `ewd-auto-connect` | `t` | Автоматически подключаться к демону при первой команде |

### Пример конфигурации

```elisp
(use-package ewd
  :load-path "~/.emacs.d/lisp/ewd"
  :custom
  (ewd-socket-path "/run/user/1000/webkit-bridge.sock")
  (ewd-default-visible t)
  (ewd-auto-connect t)
  :bind-keymap ("C-c w" . ewd-command-map))
```

## ⌨️ Использование

### Горячие клавиши

Все команды привязаны к префиксу `C-c w`:

| Клавиши | Команда | Описание |
|---------|---------|----------|
| `C-c w C` | `ewd-connect` | Подключиться к демону |
| `C-c w D` | `ewd-disconnect` | Отключиться от демона |
| `C-c w c` | `ewd-create-tab` | Создать новую вкладку (запрашивает URL) |
| `C-c w k` | `ewd-close-tab` | Закрыть вкладку по ID |
| `C-c w l` | `ewd-list-tabs` | Показать список всех вкладок в специальном буфере |
| `C-c w n` | `ewd-navigate` | Перейти по новому URL во вкладке |
| `C-c w r` | `ewd-reload` | Перезагрузить вкладку |
| `C-c w e` | `ewd-eval` | Выполнить JavaScript во вкладке |
| `C-c w s` | `ewd-shutdown` | Завершить работу демона |

### Буфер `*ewd-tabs*`

Нажмите `C-c w l`, чтобы открыть буфер вкладок. Он отображает все открытые вкладки в следующем формате:

```
EWD Tabs (2 total)
------------------------------------------------------------

* ac93f48c-9b3b-4b64-8852-966d2af207b9  Example Domain
  URL: https://example.com [owner: eff7e05a]

  bb91aed9-1d07-46ef-87ae-f4d75689881c  Google
  URL: https://google.com [owner: 00000000]
```

**Легенда:**
- `*` в начале = вкладка принадлежит этому экземпляру Emacs (можно модифицировать)
- Без префикса = вкладка принадлежит другому клиенту (только для чтения)
- `[owner: ...]` = короткий UUID клиента-владельца

**Горячие клавиши в буфере:**

| Клавиша | Команда | Описание |
|---------|---------|----------|
| `g` | `ewd-list-tabs` | Обновить список |
| `q` | `quit-window` | Закрыть буфер |
| `d` | `ewd-close-tab-at-point` | Закрыть вкладку под курсором |
| `e` | `ewd-eval-tab-at-point` | Выполнить JS во вкладке под курсором |

### Типичный рабочий процесс

1. **Запустите демон** (если не запущен как сервис):
   ```bash
   ewd-daemon
   ```

2. **Подключитесь из Emacs**:
   - Нажмите `C-c w C` (или просто выполните любую команду — автоподключение включено по умолчанию)

3. **Создайте вкладку**:
   - Нажмите `C-c w c`
   - Введите URL: `https://example.com`
   - Нажмите `RET`

4. **Просмотрите вкладки**:
   - Нажмите `C-c w l`
   - Перемещайтесь стрелками
   - Нажмите `d` для закрытия, `e` для выполнения JS

5. **Выполните JavaScript**:
   - Нажмите `C-c w e`
   - Введите ID вкладки (или используйте `e` в буфере вкладок)
   - Введите скрипт: `document.title`
   - Результат появится в минибуфере

6. **Выйдите из Emacs**:
   - Все вкладки, принадлежащие этому экземпляру Emacs, автоматически закрываются
   - Без запросов подтверждения
   - Вкладки других клиентов остаются нетронутыми

## 📖 Примеры

### Веб-скрапинг

```elisp
;; Получить заголовок страницы
(ewd-eval "tab-id" "document.title")

;; Извлечь все ссылки
(ewd-eval "tab-id" 
  "Array.from(document.querySelectorAll('a')).map(a => ({href: a.href, text: a.textContent}))")

;; Получить содержимое страницы как текст
(ewd-eval "tab-id" "document.body.innerText")
```

### Скрипт автоматизации

```elisp
(defun my-open-research-tabs ()
  "Открыть набор вкладок для исследования."
  (interactive)
  (dolist (url '("https://google.com"
                 "https://arxiv.org"
                 "https://scholar.google.com"))
    (ewd-create-tab url)))

(defun my-close-all-my-tabs ()
  "Закрыть все вкладки, принадлежащие этому экземпляру Emacs."
  (interactive)
  (dolist (tab-id ewd--my-tabs)
    (ewd-close-tab tab-id)))
```

### Интеграция с org-mode

```elisp
(defun my-org-browse-url-in-ewd (url)
  "Открыть URL в EWD вместо браузера по умолчанию."
  (interactive "sURL: ")
  (ewd-create-tab url))

;; Использовать как обработчик ссылок org-mode
(setq browse-url-browser-function #'my-org-browse-url-in-ewd)
```

## 🔧 Решение проблем

### "Socket file does not exist"

Демон не запущен. Запустите его:
```bash
ewd-daemon
```

Или проверьте, запущен ли он как systemd-сервис:
```bash
systemctl --user status ewd-daemon
```

### "Not connected to EWD daemon"

Выполните `M-x ewd-connect` или убедитесь, что `ewd-auto-connect` установлен в `t`.

### "Cannot close tab ... Not created by this instance"

Вы пытаетесь закрыть вкладку, принадлежащую другому клиенту (например, `wkctl` или другому экземпляру Emacs). Только владелец может модифицировать вкладку. Используйте `C-c w l`, чтобы увидеть, какие вкладки принадлежат вам (отмечены `*`).

### Буфер не обновляется автоматически

Буфер должен обновляться автоматически при событиях. Если этого не происходит:
1. Нажмите `g` в буфере `*ewd-tabs*` для ручного обновления
2. Проверьте, отправляет ли демон события (см. логи демона)
3. Убедитесь, что используете Emacs 30+ для лучшей совместимости

### Ошибки "Symbol's value as variable is void"

Вы используете старую версию `ewd.el`. Обновитесь до v0.6.0+, которая совместима с lexical binding Emacs 30+.

## 🏗️ Архитектура

```
┌─────────────┐         Unix-сокет             ┌──────────────────┐
│   Emacs     │  ◄──── JSON-RPC 2.0 ────►      │ webkit-bridge    │
│  (ewd.el)   │        (формат NDJSON)         │    демон         │
└─────────────┘                                └──────────────────┘
                                                      │
                                                      ▼
                                              ┌──────────────┐
                                              │  WebKitGTK   │
                                              │  (вкладки)   │
                                              └──────────────┘
```

- **Emacs-клиент** (`ewd.el`): Отправляет JSON-RPC запросы, получает ответы и уведомления
- **Демон** (`webkit-bridge`): Управляет экземплярами WebKitGTK, обеспечивает правила владения
- **Вкладки**: Реальные экземпляры браузера, принадлежащие конкретным клиентам
