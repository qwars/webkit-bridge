# EWD — Emacs-клиент для WebKit Daemon

Emacs-клиент для демона [webkit-bridge](https://github.com/qwars/webkit-bridge), обеспечивающий бесшовную автоматизацию браузера и веб-сёрфинг прямо из Emacs через WebKitGTK.

## Обзор

EWD (Emacs WebKit Daemon) — это Emacs Lisp пакет, который подключается к демону `webkit-bridge` через Unix-сокет, используя протокол JSON-RPC 2.0. Он позволяет:

- Просматривать веб-страницы с помощью WebKitGTK, не покидая Emacs
- Автоматизировать веб-взаимодействия через выполнение JavaScript
- Управлять несколькими вкладками браузера через специальный буфер
- **Показывать/скрывать вкладки интерактивно** (например, для ручного решения CAPTCHA)
- Программно извлекать веб-контент
- Интегрировать веб-сёрфинг в ваш рабочий процесс Emacs

EWD — это не браузер сам по себе. Это клиент, который взаимодействует с автономным демоном `webkit-bridge`, управляющим реальными экземплярами WebKitGTK.

## Возможности

### Управление вкладками
- Создание, закрытие, навигация и перезагрузка вкладок
- **Показ/скрытие вкладок**: переключение видимости GTK-окна для любой вкладки (полезно для CAPTCHA и интерактивных страниц)
- Специальный буфер `*ewd-tabs*` для визуального управления вкладками
- Push-обновления: буфер автоматически обновляется при любом изменении состояния вкладок (через notification `tabs_changed`)
- Сохранение позиции курсора: курсор остаётся на той же вкладке при обновлении буфера
- Визуальное различие:
  - `*` для вкладок Emacs
  - `[V]` / `[H]` для видимых / скрытых вкладок
  - Цветной текст для вкладок этой сессии
  - Серый текст для внешних вкладок

### Выполнение JavaScript
- Выполнение произвольного JavaScript в контексте любой вкладки
- Получение результатов обратно в Emacs для дальнейшей обработки
- Идеально для веб-скрапинга и автоматизации

### Безопасность и изоляция
- Контроль доступа на основе владельца: Emacs может управлять только созданными им вкладками
- Вкладки, созданные другими клиентами (например, `wkctl` или другими экземплярами Emacs), видны, но отображаются серым цветом
- Автоматическая очистка: все вкладки, принадлежащие Emacs, закрываются при выходе из Emacs (без запросов подтверждения)

### Реактивный UI
- Обновления в реальном времени через `tabs_changed` notifications от демона
- Защита буфера от редактирования с безопасным программным обновлением
- Команды работают с любой строки блока вкладки (UUID, URL или Owner)

## Требования

### Emacs
- Emacs 28.1+ (рекомендуется 30+)
- Скомпилирован с поддержкой `json-parse-string`

### Демон
- Демон `webkit-bridge` должен быть запущен
- Сокет доступен по адресу `$XDG_RUNTIME_DIR/webkit-bridge.sock` (по умолчанию)
- Переопределение через переменную окружения `EWD_SOCKET_PATH` или настройку `ewd-socket-path`
- См. [README webkit-bridge](../README.md) для установки демона

### Система
- Unix-подобная ОС с поддержкой Unix domain sockets
- Linux, BSD, macOS (с соответствующими путями к сокетам)

## Установка

### Ручная установка

Клонируйте или скопируйте `ewd.el` в ваш Emacs load path:

```bash
mkdir -p ~/.emacs.d/lisp
cp ewd.el ~/.emacs.d/lisp/
```

Добавьте в ваш `init.el`:

```elisp
(add-to-list 'load-path "~/.emacs.d/lisp")
(require 'ewd)
```

### Использование use-package

```elisp
(use-package ewd
  :load-path "~/.emacs.d/lisp/ewd"
  :config
  (setq ewd-socket-path "/run/user/1000/webkit-bridge.sock"))
```

## Конфигурация

### Переменные настройки

Доступ через `M-x customize-group RET ewd RET`:

`ewd-socket-path` `nil` (автоопределение) 
      Путь к сокету демона. Если `nil`, используется `$EWD_SOCKET_PATH`, затем `$XDG_RUNTIME_DIR/webkit-bridge.sock`

### Пример конфигурации

```elisp
(use-package ewd
  :load-path "~/.emacs.d/lisp/ewd"
  :custom
  (ewd-socket-path "/run/user/1000/webkit-bridge.sock"))
```

## Использование

### Глобальные горячие клавиши

Все команды привязаны к префиксу `C-c w`:

| Клавиши   | Команда             | Описание                                          |
|-----------|---------------------|---------------------------------------------------|
| `C-c w c` | `ewd-connect`       | Подключиться к демону                             |
| `C-c w d` | `ewd-disconnect`    | Отключиться от демона                             |
| `C-c w t` | `ewd-create-tab`    | Создать новую вкладку (запрашивает URL)           |
| `C-c w l` | `ewd-list-tabs`     | Показать список всех вкладок в специальном буфере |
| `C-c w k` | `ewd-close-tab`     | Закрыть вкладку по ID                             |
| `C-c w e` | `ewd-eval`          | Выполнить JavaScript во вкладке                   |
| `C-c w n` | `ewd-navigate`      | Перейти по новому URL во вкладке                  |
| `C-c w r` | `ewd-reload`        | Перезагрузить вкладку                             |
| `C-c w o` | `ewd-switch-to-tab` | Открыть URL вкладки в системном браузере          |
| `C-c w S` | `ewd-show-tab`      | Показать вкладку в GTK-окне                       |
| `C-c w H` | `ewd-hide-tab`      | Скрыть вкладку (перевести в headless)             |

### Буфер `*ewd-tabs*`

Нажмите `C-c w l`, чтобы открыть буфер вкладок. Он отображает все открытые вкладки в следующем формате:

```
EWD Tabs (2 open, client 1e04045b-5b84-4b71-b11f-7cb85e5f4846)
============================================================

Legend: * = owned by this Emacs session
        [V] = visible, [H] = hide
        colored text = owned by this session

* [V] [ed93a3ff-51bf-4abb-b23a-fba027dfca9f] Example Domain
  URL: https://example.com
  Owner: 1e04045b

  [H] [88341d6e-ddea-4b14-9278-e95f538c3b57] Google
  URL: https://google.com
  Owner: 00000000
```

**Легенда:**
- `*` в начале = вкладка принадлежит этому экземпляру Emacs (можно модифицировать)
- Без префикса + серый текст = вкладка принадлежит другому клиенту (только для чтения)
- `[V]` = вкладка видима в GTK-окне
- `[H]` = вкладка скрыта (headless)
- `Owner:` = короткий UUID (8 символов) клиента-владельца

### Горячие клавиши в буфере

| Клавиша     | Команда                  | Описание                              |
|-------------|--------------------------|---------------------------------------|
| `g`         | `ewd-list-tabs`          | Обновить список                       |
| `k`         | `ewd-close-tab-at-point` | Закрыть вкладку под курсором          |
| `o` / `RET` | `ewd-open-tab-at-point`  | Открыть URL вкладки в браузере        |
| `s`         | `ewd-show-tab-at-point`  | Показать вкладку в GTK-окне           |
| `h`         | `ewd-hide-tab-at-point`  | Скрыть вкладку (перевести в headless) |
| `q`         | `quit-window`            | Закрыть буфер                         |

> **Примечание:** `k`, `o`, `RET`, `s` и `h` работают с **любой строки** блока вкладки (строка с UUID, URL или Owner).

### Типичный рабочий процесс

1. **Запустите демон** (если не запущен как сервис):
   ```bash
   ewd-daemon
   ```

2. **Подключитесь из Emacs:**
   Нажмите `C-c w c`

3. **Создайте вкладку:**
   Нажмите `C-c w t`, введите URL: `https://example.com`, нажмите `RET`

4. **Просмотрите вкладки:**
   Нажмите `C-c w l`
   - Перемещайтесь стрелками
   - Нажмите `k` для закрытия, `o` или `RET` для открытия в браузере
   - Нажмите `s` для показа в GTK-окне, `h` для скрытия

5. **Решите CAPTCHA или работайте с интерактивной страницей:**
   - Нажмите `s` на вкладке, чтобы показать её GTK-окно
   - Решите CAPTCHA вручную
   - Нажмите `h`, чтобы снова скрыть окно

6. **Выполните JavaScript:**
   Нажмите `C-c w e`, введите ID вкладки, введите скрипт: `document.title`
   Результат появится в минибуфере и буфере `*ewd-eval*`

7. **Выйдите из Emacs:**
   - Все вкладки, принадлежащие этому экземпляру Emacs, автоматически закрываются
   - Без запросов подтверждения
   - Вкладки других клиентов остаются нетронутыми

## Примеры

### Веб-скрапинг

```elisp
;; Получить заголовок страницы
(ewd-eval "tab-id" "document.title")

;; Извлечь все ссылки
(ewd-eval "tab-id"
  "Array.from(document.querySelectorAll('a')).map(a => ({href: a.href, text: a.textContent}))")

;; Получить содержимое страницы как текст
(ewd-eval "tab-id" "document.body.innerText")
```

### Скрипт автоматизации

```elisp
(defun my-open-research-tabs ()
  "Открыть набор вкладок для исследования."
  (interactive)
  (dolist (url '("https://google.com"
                 "https://arxiv.org"
                 "https://scholar.google.com"))
    (ewd-create-tab url)))
```

### Интеграция с org-mode

```elisp
(defun my-org-browse-url-in-ewd (url)
  "Открыть URL в EWD вместо браузера по умолчанию."
  (interactive "sURL: ")
  (ewd-create-tab url))

;; Использовать как обработчик ссылок org-mode
(setq browse-url-browser-function #'my-org-browse-url-in-ewd)
```

## Решение проблем

### "EWD: Not connected. Run M-x ewd-connect first"

Демон не запущен или вы не подключены. Запустите его:

```bash
ewd-daemon
```

Затем выполните `M-x ewd-connect` в Emacs.

### "Socket file does not exist"

Проверьте путь к сокету:

```bash
ls -l $XDG_RUNTIME_DIR/webkit-bridge.sock
```

Если демон использует кастомный путь, установите `ewd-socket-path`:

```elisp
(setq ewd-socket-path "/custom/path/webkit-bridge.sock")
```

### Буфер не обновляется автоматически

Буфер обновляется автоматически, когда демон отправляет `tabs_changed` notifications. Если этого не происходит:

- Нажмите `g` в буфере `*ewd-tabs*` для ручного обновления
- Убедитесь, что демон запущен и подключён
- Проверьте логи демона на наличие ошибок

### "EWD: Error parsing message"

Возможно, вы используете несовместимую версию демона. Убедитесь, что используете последнюю версию демона `webkit-bridge`, которая поддерживает протокол `tabs_changed` notification.

## Архитектура

```
┌─────────────┐         Unix-сокет             ┌──────────────────┐
│   Emacs     │  ◄──── JSON-RPC 2.0 ────►      │ webkit-bridge    │
│  (ewd.el)   │        (формат NDJSON)         │    демон         │
└─────────────┘                                └──────────────────┘
       │                                              │
       │                                      ┌───────┴────────┐
       │                                      │  WebKitGTK     │
       │                                      │   (вкладки)    │
       │                                      └────────────────┘
       │
       ▼
  tabs_changed notification
  (push-обновления)
```

- **Emacs-клиент (`ewd.el`):** Отправляет JSON-RPC запросы, получает ответы и `tabs_changed` notifications
- **Демон (`webkit-bridge`):** Управляет экземплярами WebKitGTK, обеспечивает правила владения, рассылает уведомления об изменениях
- **Вкладки:** Реальные экземпляры браузера, принадлежащие конкретным клиентам
