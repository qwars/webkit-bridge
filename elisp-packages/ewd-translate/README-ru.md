# ewd-translate — Перевод через EWD и translate.ru

Emacs Lisp пакет для **перевода слов, регионов и буферов** с помощью [translate.ru](https://www.translate.ru) через систему автоматизации браузера EWD (Emacs WebKit Daemon).

**Версия пакета:** 0.1.0  
**Требования:** Emacs 28.1+, [ewd](../ewd/) 0.8.0+

## Обзор

`ewd-translate` использует фреймворк автоматизации браузера EWD для открытия скрытой вкладки WebKitGTK с translate.ru, внедрения JavaScript, перехватывающего результаты перевода, и получения богато оформленных результатов — включая словарные статьи с транскрипциями, частями речи, примерами использования и множественными вариантами перевода — прямо в буфер Emacs.

В отличие от традиционных пакетов перевода для Emacs, полагающихся на CLI-утилиты или простые HTTP API, `ewd-translate` использует полный веб-интерфейс translate.ru, предоставляя доступ ко всем словарным данным и примерам предложений.

## Как это работает

1. **Управление вкладкой** — при первом использовании `ewd-translate` ищет существующую вкладку translate.ru или создаёт новую через EWD
2. **Внедрение JS** — после загрузки страницы внедряется JavaScript, который:
   - Перехватывает `window.trru.translation.getTranslationDone` для получения результатов
   - Предоставляет функцию `window.ewdTranslate(text)` для программного запуска перевода
   - Разбирает словарный HTML (`parseDictView`) в структурированный текст
   - Отправляет результаты обратно в Emacs через `window.ewd.send('translate_result', data)`
3. **Обработка по частям** — большие тексты разбиваются на части (по умолчанию макс. 4000 символов) и переводятся последовательно
4. **Отображение результатов** — результаты выводятся в буфер `*EWD Translate*` с семантической подсветкой

## Возможности

### Команды перевода

| Команда                | Клавиши   | Описание                     |
|------------------------|-----------|------------------------------|
| `ewd-translate-word`   | `C-c t w` | Перевести слово под курсором |
| `ewd-translate-region` | `C-c t r` | Перевести выделенный регион  |
| `ewd-translate-buffer` | `C-c t b` | Перевести весь буфер         |

### Словарный вид

При переводе слова или короткой фразы translate.ru возвращает полную словарную статью:

- **Форма слова** с транскрипцией (например, `evolution [ˌevəˈluːʃn]`)
- **Часть речи и грамматические формы** (существительное, спряжения глаголов и т.д.)
- **Варианты перевода** с дополнительной информацией
- **Примеры использования** с исходным текстом и переводом

### Обработка текста

- **Перевод по частям** — большие тексты разбиваются на части (настраивается, по умолчанию 4000 символов)
- **Нормализация переносов** — слова, разорванные на разные строки мягкими переносами, соединяются
- **Нормализация пробелов** — множественные пробелы схлопываются; переводы строк сохраняются
- **Индикация прогресса** — ожидающие части отображаются как `[ожидает...]` до завершения перевода

### Отображение буфера

Буфер `*EWD Translate*` использует `special-mode` с пользовательскими лицами (faces):

| Лицо                             | Применяется к                                  |
|----------------------------------|------------------------------------------------|
| `ewd-translate-header-face`      | Заголовки сессий (`=== Метка ===`)             |
| `ewd-translate-form-face`        | Словарные формы слов + транскрипция            |
| `ewd-translate-translation-face` | Строки перевода                                |
| `ewd-translate-ref-face`         | Справочная информация (часть речи, примечания) |
| `ewd-translate-example-face`     | Строки примеров                                |
| `ewd-translate-separator-face`   | Разделители (`────`)                           |
| `ewd-translate-error-face`       | Сообщения об ошибках                           |
| `ewd-translate-pending-face`     | Заполнители ожидающих частей                   |

### Автоматизация

- **Автозапуск** — при запуске Emacs пакет автоматически подключается к EWD и подготавливает вкладку перевода
- **Повторное использование вкладки** — если вкладка translate.ru уже существует, она используется повторно вместо создания новой
- **Очередь операций** — если вкладка перевода ещё не готова, запросы ставятся в очередь и выполняются после готовности

## Требования

- Emacs 28.1+ (с поддержкой `json-parse-string`)
- [ewd](../ewd/) 0.8.0+ — пакет EWD-клиента (загружается автоматически)
- `ewd-daemon` — демон WebKitGTK (должен быть собран и доступен в `PATH`)
- Подключение к интернету (для доступа к translate.ru)

Инструкции по установке демона см. в [README webkit-bridge](../../README-ru.md).

## Установка

### Ручная установка

Скопируйте директорию `ewd-translate/` в ваш Emacs load path:

```bash
mkdir -p ~/.emacs.d/lisp
cp -r ewd-translate/ ~/.emacs.d/lisp/
```

Добавьте в ваш `init.el`:

```elisp
(add-to-list 'load-path "~/.emacs.d/lisp/ewd-translate")
(require 'ewd-translate)
```

### Использование use-package

```elisp
(use-package ewd-translate
  :load-path "~/.emacs.d/lisp/ewd-translate"
  :after ewd)
```

## Конфигурация

Все настройки доступны через `M-x customize-group RET ewd-translate RET`:

| Переменная                        | По умолчанию                         | Описание                                            |
|-----------------------------------|--------------------------------------|-----------------------------------------------------|
| `ewd-translate-max-chunk-length`  | `4000`                               | Максимальная длина части текста для перевода        |
| `ewd-translate-url`               | `"https://www.translate.ru/перевод"` | URL сервиса перевода                                |
| `ewd-translate-js`                | `""` (встроенный)                    | Пользовательский JavaScript код или путь к JS-файлу |
| `ewd-translate-page-load-timeout` | `30`                                 | Секунд ожидания загрузки страницы перевода          |

### Пользовательский JavaScript

Если вы хотите использовать другой сервис перевода или изменить логику внедрения, установите `ewd-translate-js` в:

- строку с JavaScript кодом, или
- путь к `.js` файлу

Если значение пустое (по умолчанию), используется встроенный скрипт, разработанный специально для translate.ru.

### Пример конфигурации

```elisp
(use-package ewd-translate
  :load-path "~/.emacs.d/lisp/ewd-translate"
  :after ewd
  :custom
  (ewd-translate-max-chunk-length 2000)
  (ewd-translate-page-load-timeout 45))
```

## Использование

### Базовое использование

1. **Убедитесь, что демон запущен** (EWD автоматически запустит его, если он в `PATH`):
   ```bash
   ewd-daemon
   ```

2. **Переведите слово** — установите курсор на слово и нажмите `C-c t w`:
   ```
   Результат в *EWD Translate*:
   === Word: evolution ===
   evolution [ˌevəˈluːʃn]
       эволюция, развитие
       › The theory of evolution is well established.
       › Теория эволюции хорошо обоснована.
   ```

3. **Переведите регион** — выделите текст и нажмите `C-c t r`:
   ```
   === Region (127 chars) ===
   [ожидает...]
   [ожидает...]
   ```

   Результаты появляются по мере обработки частей:
   ```
   === Region (127 chars) / 2 chunks ===
   This is the first chunk...
   Это первый фрагмент...

   This is the second chunk...
   Это второй фрагмент...
   ```

4. **Переведите буфер** — нажмите `C-c t b` для перевода всего текущего буфера.

### Горячие клавиши

| Клавиши   | Команда                | Описание                     |
|-----------|------------------------|------------------------------|
| `C-c t w` | `ewd-translate-word`   | Перевести слово под курсором |
| `C-c t r` | `ewd-translate-region` | Перевести выделенный регион  |
| `C-c t b` | `ewd-translate-buffer` | Перевести весь буфер         |

### Просмотр результатов

Буфер `*EWD Translate*` открывается автоматически после завершения перевода. Он доступен только для чтения (`special-mode`) с подсветкой содержимого. Используйте стандартную навигацию Emacs для просмотра результатов.

## Примеры

### Перевод слова

```elisp
;; Установите курсор на слово "evolution" и:
M-x ewd-translate-word
;; или нажмите: C-c t w

;; Вывод в *EWD Translate*:
;; === Word: evolution ===
;; evolution [ˌevəˈluːʃn]
;;     эволюция, развитие
;;     › The theory of evolution
;;     › Теория эволюции
```

### Программный перевод региона

```elisp
;; Выделите текст в текущем буфере, затем:
(ewd-translate-region (region-beginning) (region-end))

;; Или программно:
(let ((text "The quick brown fox jumps over the lazy dog."))
  (with-temp-buffer
    (insert text)
    (ewd-translate-region (point-min) (point-max))))
```

### Настройка размера части

```elisp
;; Для более быстрых переводов (меньшие части):
(setq ewd-translate-max-chunk-length 1000)

;; Для меньшего количества запросов (большие части):
(setq ewd-translate-max-chunk-length 8000)
```

## Решение проблем

### "EWD daemon not connected"

Убедитесь, что `ewd-daemon` запущен и EWD подключён:

```bash
ewd-daemon
```

Затем выполните `M-x ewd-connect` в Emacs перед попыткой перевода.

### Вкладка перевода не загружается

- Проверьте подключение к интернету
- Убедитесь, что translate.ru доступен
- Увеличьте `ewd-translate-page-load-timeout`, если страница загружается медленно
- Проверьте буфер `*EWD Debug*` (из `ewd-debug.el`) для логов IPC

### Ошибка "Empty text"

Регион или буфер, который вы пытаетесь перевести, не содержит текста. Выберите непустой регион или переместите курсор на слово.

### Результаты перевода пусты

- Убедитесь, что JavaScript включён во вкладке WebKitGTK (включён по умолчанию)
- Проверьте, не изменилась ли структура страницы translate.ru (возможно, требуется обновление JS)
- Попробуйте установить пользовательский `ewd-translate-js` для адаптации к изменениям

### Таймаут

Если страница перевода загружается слишком долго:

```elisp
(setq ewd-translate-page-load-timeout 60)
```

### Порядок работы

1. Пользователь вызывает команду перевода (`ewd-translate-word`, `ewd-translate-region` или `ewd-translate-buffer`)
2. Текст разбивается на части (макс. `ewd-translate-max-chunk-length` символов каждая)
3. Части последовательно отправляются через `ewd-eval-async` на вкладку translate.ru с вызовом `window.ewdTranslate(text)`
4. Внедрённый JS заполняет форму перевода, нажимает кнопку перевода и перехватывает результат
5. Результаты (словарный HTML или простой текст) отправляются обратно в Emacs через JS-мост (`window.ewd.send`)
6. Обработчик `translate_result` обновляет буфер `*EWD Translate*` форматированным выводом с подсветкой
7. Следующая часть отправляется автоматически, пока не будут обработаны все части
